# Masato Kuratani Portfolio

プロダクトデザインとフロントエンド開発を中心とした、倉谷将人のポートフォリオサイトです。

## About

Web サイトやアプリケーションの設計、UI デザイン、フロントエンド実装に取り組んでいます。

## Works

制作実績はサイト内の [Work ページ](https://github.com/kuratanimasato/Astro-my-Portfolio) で紹介しています。

## Tech Stack

- Astro
- TypeScript
- Tailwind CSS
- Content Collections
- HTML / CSS / JavaScript

## Development

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:4321` を開いてください。

```bash
npm run check
npm run build
npm run format:check
```
